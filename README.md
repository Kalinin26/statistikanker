# Statistik Anker – Website

Statische Website für statistikanker.de (reines HTML/CSS, kein Build-Schritt).

## Struktur
- `index.html` – Startseite
- `leistungen.html`, `methoden.html`, `preise.html`, `ueber-mich.html`, `kontakt.html`
- `impressum.html`, `datenschutz.html`
- Foto, Favicon und lokal eingebundene Schrift (Plus Jakarta Sans, OFL-Lizenz) liegen direkt im Hauptordner
- `sitemap.xml`, `robots.txt`

## Vor dem Livegang
- In `datenschutz.html` Hosting-Anbieter und Speicherdauer der Logfiles eintragen.
- Nach dem Livegang `sitemap.xml` in der Google Search Console einreichen.
